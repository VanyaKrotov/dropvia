# Структура лендинга Dropvia

Текущая версия28октября2026: структура и взаимодействия по живому референсу [WorkOS AuthKit](https://workos.com/authkit?ref=authkit). `DESIGN.md` остаётся неизменённым стилевым источником; продуктовые факты — `PRODUCT.md` и задачи владельца. Референс изучен в браузере: первый экран, feature columns, vertical tabs и смена сцен, platform grid, нижние секции. Его текущая светлая палитра не заменяет систему Dropvia и темы устройства.

Аудитория: обычные пользователи с документами, фото и проектными материалами. Ценность: личное файловое пространство для хранения, передачи и скачивания. Основная доступная CTA — заявка. Все готовые тексты EN/RU находятся в `src/shared/i18n/en.ts` и `ru.ts`. Без вымышленных клиентов, отзывов, квот, uptime, security claims или возможностей AuthKit.

## Анимация

Карточка браузерного доступа в Platform: «Доступно с любого устройства.» / “Available on any device.” Подзаголовок: «Удобный веб-интерфейс доступен с любого браузера и устройства.» / “An easy-to-use web interface, available in any browser and on any device.” Миниатюра повторно использует hero dashboard в размере800px и общую панель Safari; изображение целиком, без crop, с локалью и темой устройства.

Фокус — смена трёх файловых сцен по выбору пользователя (260ms, opacity и небольшой y), а не имитация реальной загрузки. Supporting illustrations появляются один раз при входе в viewport (650ms; соседние колонки имеют ограниченный stagger). Hero сохраняет fade-in900ms и подъём12px после загрузки изображений. Header/FAQ/copy/form сохраняют существующие взаимодействия.

`useLandingMotion` владеет IntersectionObserver, controls и подпиской reduced motion через useSyncExternalStore. По умолчанию SSR/no-JS контент видим; скрываются только offscreen visuals после JS enhancement. При reduced motion или отсутствии observer движения не нужны. Cleanup останавливает animations/observer и возвращает видимость. Никаких autoplay loops, mandatory scroll lock, parallax или скопированных удалённых animation scripts.

## Карта и ограничения

`/` EN, `/ru` RU; страницы /prices, /api/, /status, /terms, /privacy и их локализованные пары сохранены. Header CTA Sign in / «Войти» ведёт на локализованную /sign-in по задаче владельца29October2026; language links сохраняют путь/query/hash. Hero, тарифы и подвал сохраняют ссылки на #request-access. На странице входа под email/password формой также есть ссылка на заявку; свободная регистрация не добавлена.

SEO остаётся noindex до разрешённого запуска. Уникальные SSR metadata/canonical/hreflang на dropvia.fun сохранены; sitemap.xml содержит12 EN/RU canonical страниц по запросу владельца, включая вход, кроме статуса и скрытых узлов; noindex пока сохранён. Private file endpoints не включаются в sitemap. Никаких fake ratings, MAUs или достижений.

Файловые серверные контракты по-прежнему заглушки403/404, заявка201 без хранения/писем, status — синтетический снимок по исходной задаче. Цены, квоты, восстановление и опции тарифов утверждены владельцем: `docs/PRICING.md`. Реальные backend интеграции, биллинг, оператор и прочие условия хранения остаются открытыми. См. `docs/API.md` и `PRODUCT.md`.

Референс — источник композиции и взаимодействий, а не Dropvia feature specification. Не переносятся функции и цены AuthKit. SSO в Advanced взят из отдельно утверждённого тарифного скриншота, а не из визуального референса. MFA/SCIM, auth installer, AI agents, пользователи WorkOS и security certifications не добавляются. Сгенерированные Dropvia screenshots не заменяются HTML-копией AuthKit.
