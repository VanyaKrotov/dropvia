# Структура и контент Dropvia

## Что известно

Из исходной задачи подтверждены: Dropvia, домен `https://dropvia.fun`, назначение — загрузка, передача и скачивание файлов. Уточнение владельца 28 октября 2026: простое файловое хранилище для обычных пользователей по типу Dropbox/Mega; английский по умолчанию и русский. Эти ориентиры описывают категорию, а не обещают все функции упомянутых продуктов. `DESIGN.md` полностью посвящён визуальному reference AuthKit и сам не подтверждает продуктовые сценарии или коммерческие условия.

Диагноз копирайтинга A: известны категория и широкая аудитория, но нет утверждённой функциональности, differentiator и proof points. Можно написать честный статус, но нельзя обосновать обещания скорости, безопасности, бесплатности и удобства относительно конкурентов. Английский — основной, русский — дополнительный; географические рынки не определены.

## SEO-план

- Сейчас `/` (en), `/ru` (ru), `/robots.txt`, `/sitemap.xml`; неизвестные HTML URLs — настоящий 404.
- EN title: «Dropvia — file storage and sharing». EN description: «Dropvia is a file storage service for uploading, sharing and downloading files. The service is in development.» Canonical: `https://dropvia.fun/`.
- RU title: «Dropvia — хранение и передача файлов». RU description: «Dropvia — файловое хранилище для загрузки, передачи и скачивания файлов. Сервис в разработке.» Canonical: `https://dropvia.fun/ru`. Reciprocal hreflang en/ru/x-default, html lang из серверного URL. Без автоматической подмены языка по геолокации.
- OG title/description/type/locale/url и Twitter summary передаются SSR. Не заявлять наличие social image, пока его нет.
- Подготовительный экран `noindex, nofollow`; robots разрешает crawl, чтобы поисковик прочитал noindex. Индексируемых URL пока нет: `/sitemap.xml` возвращает 204 без тела и не рекламируется в robots. Пустой urlset невалиден по [официальной XSD](https://www.sitemaps.org/schemas/sitemap/0.9/sitemap.xsd), поэтому XML sitemap до запуска не публикуется.
- После реального запуска: утверждённые title/description и тексты, убрать noindex, вернуть валидный XML sitemap с обеими canonical версиями и добавить Sitemap directive в robots, подготовить OG raster, проверить Search Console и реальные метрики.
- File/download links по умолчанию приватные и вне sitemap; окончательные правила доступа требуют продукта. Robots не контролирует доступ.
- Structured data отложены до indexable launch; skill `schema` установлен для проверки реальных сущностей. Нет Product ratings, цен или FAQ claims.
- Keyword research и content calendar отложены до определения продуктовых сценариев и рынков: выдуманные volumes и SEO score не приводятся.
