# Аудит кода Dropvia

Источник требований: текущая задача владельца, AGENTS.md, PRODUCT.md, DESIGN.md, docs/API.md, docs/PRICING.md и docs/ARCHITECTURE.md. Проверяем весь написанный runtime-код в src/, тесты, конфигурацию и собственные scripts; vendored skills и generated build не переписываем. Базовый Git HEAD fdc7fb792b9044a5990c3b76936de9284bae0396 содержит подготовительный экран, поэтому аудит использует полный снимок рабочей копии с SHA-256: docs/audits/2026-10-29/baseline.json.

1. Независимые read-only проходы Standards и Spec; основной проход по серверным границам, ошибкам, состояниям и контролю качества.
2. Проверка FSD-направлений/циклов, типов, ответственности модулей, React SSR, подписок/motion, i18n и contracts. Отделять дефекты от вкусовых предпочтений; не вводить паттерны без практической необходимости.
3. Воспроизвести подтверждённые проблемы тестами, исправить минимальным изменением. Не реализовывать отсутствующий backend, auth sessions, billing или deployment.
4. Полный npm run check (при ресурсном ограничении браузеры4 workers), SSR/no-JS, browser/axe и реальные screenshots для затронутого UI. Отдельно указать непройденные проверки и фактические ограничения.
5. Итоговый отчёт docs/audits/2026-10-29/REVIEW.md: Standards и Spec отдельно, доказательства, исправления и отложенные вопросы. Сохранить исходный продукт и дизайн.
