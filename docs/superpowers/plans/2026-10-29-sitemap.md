Задача владельца: добавить все страницы кроме `/_data/*` и `/status`. Обе локали включены; текущие12 canonical URL в домене dropvia.fun. Не включать JSON endpoints и ошибки. Явная задача отменяет прежний sitemap204, но не является разрешением снять noindex или выполнить deployment.

1. Общий `pagePaths` в shared/seo/metadata.ts используется canonical и sitemap; никаких дублирующих реестров.
2. Resource route app/routes/sitemap.ts отдаёт валидный UTF-8 XML с200, namespace, loc и cache; app/routes/robots.ts указывает его URL.
3. app/routes/sitemap.test.ts проверяет XML и точный набор, tests/e2e/ssr.spec.ts — реальные HTTP200 и canonical всех адресов. Не выдумывать даты обновления.
4. Обновить текущие README/AGENTS/architecture/landing docs; исторические отчёты прежнего этапа сохраняют прошлые результаты.
5. Проверить skills, format, lint, typecheck, unit tests, build и metadata/SSR browser tests на трёх viewport проектах.
