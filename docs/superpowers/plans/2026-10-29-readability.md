# Форматирование и читаемость

Задача: привести собственные src/, tests/, scripts/ и конфигурацию к читаемому единому стилю без изменения продукта, дизайна или контрактов.

Порядок: сохранить контрольные хэши исходных файлов → явные блоки управления (ESLint curly) и пустые строки между объявлениями/логическими шагами → Prettier по существующей конфигурации → просмотреть механические правки и проверить сохранение наблюдаемого поведения → npm run check. Не добавлять библиотеки, универсальные обёртки, новые бизнес-функции или тесты косметики. DESIGN.md и vendored skills не менять.

Выполнено: явные curly-блоки во всех собственных JS/TS файлах, отступы Prettier90, пустые строки между объявлениями, guard clauses и шагами обработки. Порядок импортов и вычислений сохранён. Правило curly=all настроено после eslint-config-prettier; effective config проверен (severity2). Без новых production abstractions и тестов косметики. Финальный npm run check: exit0,46 unit и138 Playwright scenarios; skills/format/lint/typecheck/build прошли. Первоначальный lint задел временный QA-helper в artifacts; helper удалён, исходники не исключались из проверок.
