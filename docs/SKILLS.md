## Установленные навыки

P1 — основной для области, P2 — дополняет, P3 — точечный инструмент. Приоритет не отменяет `DESIGN.md`. «Проверен» означает manifests/references/license evidence/source pin + фактическое обнаружение Codex; не означает выполнение каждого script или доказательство каждой рекомендации.

Метод **A**: Skills CLI 1.7.4 из npm, `add <путь проверенного commit-снимка> --skill <upstream-name> -a codex --copy -y`, без global и с `DISABLE_TELEMETRY=1`, `npm_config_ignore_scripts=true`. Перед установкой исполнены `--help` и `add --help`, args проверены по [официальному CLI source](https://github.com/vercel-labs/skills). Установка из локального снимка исключает подмену HEAD между просмотром и копированием. GitHub ref/источник перенесены в lock вместо временных путей.

Метод **B**: официальный source renderer `cli/src/utils/template.ts::generatePlatformFiles(stage, 'codex')` с Node strip-types, затем A только для сгенерированного `ui-ux-pro-max`. Стандартный специализированный installer автоматически копирует ещё шесть sibling skills; они не нужны и не перенесены.

## Проверка обнаружения и сохранности

- Реальный `Skills CLI list -a codex --json` видит local project skills. Он не является доказательством Codex discovery сам по себе.
- Дополнительно выполнен **Codex app-server `initialize` → `skills/list` с forceReload=true**. Сам Codex вернул 22 навыка с `scope=repo`, `enabled=true`, без ошибок manifest. Без model turn, записи настроек и установки plugins. Сохранено `codex-skills-discovery.json`.
- `node scripts/check-codex-skills.mjs <путь-к-codex.exe>` повторяет необязательную локальную проверку. CI не требует установленного Codex.
- `npm run skills:verify` проверяет уникальные names, наличие manifests/resources/license evidence, pinned commits и SHA-256 всего выбранного набора. `skills-integrity.json` нормализует CRLF для Git cross-platform checkout; это контроль drift, не антивирус и не гарантия поведения модели.
- Alias меняет только manifest name и имя директории трёх навыков. Дополнительно текстовые окончания строк всех vendored файлов нормализованы в LF для одинаковых Windows/Linux hashes. Оригинальные names, изменения и полные commits — в sources registry. Это устраняет совпадения с уже установленными глобальными навыками пользователя.
- Регистр не доказывает фактическое следование инструкциям: для этого `AGENTS.md` требует загрузки навыка по матрице и проверки результата. Новые навыки доступны на следующей реплике; если selector не обновился, перезапустить Codex.

## Безопасность и зависимости

Непроверенные remote install scripts, lifecycle scripts, secrets, сторонние hooks и глобальные plugins не использовались. Были прочитаны инструкции и исполняемые entry points. Опциональные scripts не запускаются при обычном приложении или CI. Проверка не является полной независимой security audit всех 351 vendored files.

UI/UX Pro Max: официальный README предлагает `ui-ux-pro-max-cli` (не старый uipro-cli), `uipro init --ai codex`, поддерживает offline и dry-run. Проверенный source package.json содержит 2.5.0, npm в этот момент предлагает 2.15.0, а npm 2.5.0 отсутствует (ETARGET). Вместо исполнения другой непроверенной публикации использован прочитанный source renderer закреплённого commit. Его base templates, CSV и scripts включены; лишние sub-skills не установлены. Python stdlib search запущен: общий design-system результат не соответствовал pinned палитре и не был принят, targeted `visible keyboard focus` вернул подходящие UX rules. Для скриптов можно использовать любой Python 3; конкретный bundled Python разработчика не нужен в repo.

Impeccable 4.8.0: installer сейчас устанавливает native hook manifests, launcher может скачивать self-contained engine в пользовательский cache. Для этой задачи это лишние побочные эффекты. Сохранены skill/references/launcher source и лицензия; launcher **не исполнялся**, hook не установлен, engine не загружен. Используется описанный в skill fallback ручного чтения контекста. Не называть такой аудит выполненным binary detector scan.

Taste: Node 22+, Chrome/Edge/Chromium для optional inspector, сеть только для поиска imagery. Требования случайного направления, 4 картинок и ≥8 движений противоречат текущему brief; они явно уступают `DESIGN.md`. Не загружать чужие изображения или декоративные зависимости ради его score.

License caveat Vercel: React/composition manifests объявляют MIT. У web-design-guidelines лицензия объявлена README всего repo; standalone license file в источнике не предоставлен. Его README и точный URL сохранены в `UPSTREAM-LICENSE.md`; правообладатель и полный grant не выдуманы. Anthropic Frontend Design содержит Apache-2.0 LICENSE.txt, хотя GitHub metadata всего mixed-license repo не определяет одну лицензию. Impeccable Apache NOTICE также сохранён.

## Что не установлено

- Архивный `react-router-framework-mode`: заменён официальным `react-router` с framework reference и docs установленной версии, как требует README автора. Двух основных routing sources нет.
- `ai-seo`: проверен, но пока нет содержательной публичной страницы, аудитории с исследованным search intent и данных AI visibility. Вернуться после реального контента; не обещать AI-цитируемость.
- Дубликат Impeccable Frontend Design, полный UI/UX пакет sibling skills, Matt TDD/debug и Superpowers review/orchestrators: пересекаются с выбранными навыками, не добавлены.
- Глобальные setups, hooks, automatic issue tracker integration, publishing/deploy skills: вне задачи.

## Обновление

Следовать процедуре README, не выполнять blind update. `skills-lock.json` содержит источники и refs вместо temp paths; generated UI skill имеет local source с remote provenance, поскольку его нельзя восстановить простым копированием upstream pointer directory. Alias также нужно восстановить после update. Перед изменением hash registry сначала review upstream diff и зависимости. Автоматическое обновление не настроено.
