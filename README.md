# Развёртывание Dropvia

## Требования

Сервер Ubuntu amd64 с systemd, доступом в интернет и установленным curl. Для запуска нужны права root или sudo. Скрипты установки должны быть опубликованы в ветке main, а образ сервиса — в latest-релизе репозитория.

## Установка

Подключитесь к серверу по SSH и перейдите в root:

```bash
sudo -i
```

Запустите установку:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/VanyaKrotov/dropvia/main/scripts/deploy.sh)
```

Скрипт установит недостающие компоненты, Docker и CLI Dropvia, затем скачает и запустит контейнер. При установке укажите IP интерфейса и порт. Если Dropvia уже установлен, потребуется подтверждение переустановки.

Для доступа извне укажите `0.0.0.0`, для работы через reverse proxy — `127.0.0.1`. После установки откройте `http://<IP-сервера>:<порт>`. Для внешнего доступа порт должен быть разрешён в настройках сети и firewall; домен и HTTPS настраиваются отдельно.

## Управление

| Команда                   | Действие                                                         |
| ------------------------- | ---------------------------------------------------------------- |
| `sudo dropvia up`         | Запустить контейнер                                              |
| `sudo dropvia down`       | Остановить контейнер                                             |
| `sudo dropvia update`     | Обновить сервис до последнего релиза                             |
| `sudo dropvia update-cli` | Обновить CLI                                                     |
| `sudo dropvia install`    | Повторить установку или переустановить сервис                    |
| `sudo dropvia uninstall`  | Удалить контейнер, образ и CLI с подтверждением каждого действия |

Если установка завершилась ошибкой, устраните указанную причину и повторите команду. Подробности: [инструкция по развёртыванию](docs/DEPLOY.md).
